struct Client

since 0.2.0 linux-64 · linux-aarch64 · osx-arm64 documentation supplied by the publisher Mojo 1.0.0 
struct Client(Movable, Stringable)

An HTTP/1.1 client that keeps one connection pool per host. Every request made through a Client shares its pool and its default timeout; a Client owns its pool and closes it when it is destroyed.

Example: reuse one client mojo
2 setup lines, not copied unless shown 
from http_client.testing import serve_fixture
var server = serve_fixture("two_paths")
from http_client.client import Client

def main():
    var client = Client(timeout_ms=2000)
    for path in ["/a", "/b"]:
        var r = client.get(server.url + path)
        print(path, r.status)
Output
/a 200
/b 404

fnget #

since 0.3.0 
fn get(
    mut self,
    url: String,
    *,
    headers: Headers = Headers(),
    timeout_ms: Optional[Int] = None,
) raises -> Response

Sends a GET request and reads the whole response body. Reuses a pooled connection to the host when one is idle.

Parameters, returns, raises and an example
Example: a request with headers mojo 
var h = Headers()
h.set("Accept", "application/json")
var r = client.get("https://example.com/api", headers=h)

Parameters

urlStringAn absolute http:// or https:// URL.
headersHeadersExtra request headers. Host and Content-Length are set for you.
timeout_msOptional[Int]Overrides the client's default timeout for this request.

Returns

Response: the status, headers and body. A 4xx or 5xx status is a response, not an error.

Raises

TimeoutErrorwhen no complete response arrives within the timeout.
HttpErrorwhen the URL is not absolute or the connection fails.
