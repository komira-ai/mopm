http_client #

A small, dependable HTTP/1.1 client written in Mojo. It keeps connections alive in a pool, applies a timeout to every request and can stream large response bodies without buffering them.

Usage #

from http_client import Client

def main():
    var client = Client(timeout_ms=5000)
    var resp = client.get("https://example.com/")
    print(resp.status, len(resp.body))

Features #

  • Keep-alive connection pool, one per host.
  • Per-request timeouts with a clear TimeoutError.
  • Streaming bodies through Response.chunks().
  • No global state; every Client owns its pool.
