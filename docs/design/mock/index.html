Quickstart

Three steps to your first dependency

  1. 1

    Install mopm

    One line once release binaries ship; from source with Zig until then.

    curl -fsSL https://mopm.dev/install.sh | sh
  2. 2

    Add a package

    In a pixi project that lists the mopm channel. mopm add is planned.

    pixi add mojo-json
  3. 3

    Use it

    Import it in Mojo, then run your tests with mopm test.

    from json import parse

def main():
    v = parse('{"ok": true}')
