usage: mopm package versions <namespace>/<name> [--cursor <cursor>] [--limit <n>] [--registry <prod|gamma|beta|url>] [--config-dir <dir>] [--json]

List the versions of a package.

Includes yanked and tombstoned versions, with their state.

arguments:
  <namespace>/<name>
      The namespace of the package, a GitHub login in lower case.
      Normalised package name, the part of the full name after the `/`.
options:
  --cursor <cursor>
      Opaque. Pass the `next_cursor` of the previous page.
  --limit <n>
  --registry <prod|gamma|beta|url>
      the registry (default prod)
  --config-dir <dir>
      where 'mopm login' keeps credentials.json (default ~/.config/mopm)
  --json
      print the registry's answer as JSON instead of text

Sends GET /api/v2/packages/{namespace}/{name}/versions (listVersions).
