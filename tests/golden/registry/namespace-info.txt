usage: mopm namespace info <namespace> [--registry <prod|gamma|beta|url>] [--config-dir <dir>] [--json]

Show a namespace: its kind and its GitHub account.

arguments:
  <namespace>
      The namespace of the package, a GitHub login in lower case.
options:
  --registry <prod|gamma|beta|url>
      the registry (default prod)
  --config-dir <dir>
      where 'mopm login' keeps credentials.json (default ~/.config/mopm)
  --json
      print the registry's answer as JSON instead of text

Sends GET /api/v2/namespaces/{namespace} (getNamespace).
